# Output template

Write the report in the language the user asks for. Default: English.
Target length: 2–3 pages. A CEO should get the point from section 1 alone.

---

## 1. Executive summary (5 lines max)
- Where the client wins
- Where the client loses to the benchmark, and in which market
- The single highest-ICE action
- The cross-market bet

## 2. URL map
Table from Phase 1.

## 3. Gap matrix
Rows = dimensions. Columns = one Client | Bench pair per market, in the order given. Default: Client FR | Bench FR | Client ES | Bench ES | Client UK | Bench UK (EN = UK).
If a brand does not operate in a market, keep the column and write "not present" (it is a finding).
Cells = score 1–5. Mark gaps of 2+ points.
Below the table: one evidence line per marked gap.

## 4. Key findings by market
3 bullets per market, most important first. Each bullet = observation + evidence + so-what.

## 5. ICE backlog
Top 3 quick wins per market + 1 cross-market bet (format from `ice.md`).

## 6. 30-day test plan
Table from `ice.md`.

## 7. Method & limits
- Date of audit, sources used
- What was not observable and why
- "Signals, not spend" disclaimer for paid data
- AI answers are a directional sample, not a ranking
